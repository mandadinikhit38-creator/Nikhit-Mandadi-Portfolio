# Responsible security disclosure

If you identify a security issue in this static portfolio, use the contact method in `/.well-known/security.txt`. Include the affected page or asset, the steps needed to reproduce the issue, and its potential impact. Do not include unrelated personal information in a report.

Please allow up to five business days for an initial response and up to 30 days for investigation or a remediation update. The site owner will not pursue legal action for good-faith security research conducted within applicable law, without disrupting services, accessing data that is not yours, or publicly disclosing an issue before coordinating a fix.

This policy does not authorize testing other systems, accounts, networks or services. The contact and canonical URL in the disclosure file must be replaced with current owner-controlled values before publication.
